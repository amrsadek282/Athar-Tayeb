# أثر طيب

موقع تذكاري عربي متجاوب للقرآن والذكر والدعاء. يبدأ بالوضع الداكن افتراضيًا، ويمكن للزائر التبديل إلى الوضع الفاتح مع حفظ اختياره محليًا.

## هيكل المشروع

```text
athar-update/
├── index.html
├── README.md
└── assets/
    ├── favicon.svg
    ├── css/
    │   └── style.css
    └── js/
        ├── app.js
        ├── quran-data.js
        ├── zikr-data.js
        └── duas-data.js
```

## النشر على Vercel

1. ارفع محتويات هذا المجلد كاملة إلى GitHub مع الحفاظ على مجلد `assets`.
2. اربط المستودع بمشروع جديد في Vercel.
3. اختر Framework Preset: Other، واترك Build Command وOutput Directory فارغين.
4. انشر المشروع، وتأكد أن `index.html` في جذر المشروع.

## ملاحظات

- الوضع الداكن هو الافتراضي حتى للزائر الجديد، بينما يحفظ الموقع اختيار الثيم محليًا بعد تغييره.
- أيقونة المتصفح في `assets/favicon.svg`.
- الألوان والتصميم في `assets/css/style.css`.
- التفاعلات في `assets/js/app.js`، والبيانات في ملفات JavaScript المنفصلة.
- روابط الصوت تعتمد على خادم MP3Quran وتتطلب اتصالًا بالإنترنت.
- بعض نصوص القرآن الموروثة من النسخة السابقة مقتطفات وليست سورًا كاملة؛ راجعها من مصحف موثوق قبل تقديمها على أنها كاملة.
- عداد التسبيح محفوظ محليًا في متصفح كل زائر ولا يُرسل إلى خادم.
